# Property catalogs

Each subdirectory holds one property catalog. `METHOD.md` defines the record
contract. It is copied from the eidnara repository at
`bb866266cff57664ff7199d166a3290f11607a58` and kept by review.

Part directories do not exist before the ticket that lands them.
`scripts/check-catalog.ts` checks each record against `METHOD.md`.
